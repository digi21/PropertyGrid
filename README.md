# Digi21.WinUI.PropertyGrid

A property grid for WinUI 3. Give it an object and it lists the object's properties as editable rows,
choosing an editor per property type, grouping them into categories, and letting you replace any part
of the presentation from XAML.

Work in progress — the first release is not out yet.
